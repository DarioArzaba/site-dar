## About

Personal blog to organize notes and ideas build with Astro and deployed to Cloudflare using MDX for content and React islands for interactivity.

## Installation

1. Clone
   ```sh
   git clone https://github.com/DarioArzaba/site-dar
   cd site-dar
   ```
2. Install
   ```sh
   npm install
   npm rebuild
   ```
3. Deploy
   ```sh
   npm run build
   npm run dev
   ```

## Usage

Organized into top level categories dashboard, each with subcategories that link to individual notes or a list of notes. Notes are written in MDX with mostly standard Markdown formatting.

**Design details:**
- **Font**: Open Sans Variable (`@fontsource-variable/open-sans`)
- **Colors (light)**: background `#efefe7`, ink `#282828`, accent `#007ab3`
- **Colors (dark)**: background `#050606`, ink `#e1e1eb`, accent `#72c6ea`
- **Category accent colors**: Programming `#2b69b1`, Engineering `#01818f`, Personal `#c64539`, Media `#6655c9`, Languages `#845b02`, Biology `#349b60`, History `#a44f8a`, Philosophy `#4e1d5f`, Others `#5e6978`
