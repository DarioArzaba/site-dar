# QuickStart

## Install

```shell title:"Install Rust"
# Install in Linux
# rustup is the official rust toolchain installer
# Installed on $HOME/.cargo/bin or %USERPROFILE%\.cargo\bin
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Validate installation (compiler, cargo, doc generator)
rustc --version
cargo --version
rustdoc --version

# Uninstall
rustup self uninstall

sudo chown -R dario:dario /home/dario
```

```shell title:"Compile Rust"
rustc main.rs
./main
```

# Fundamentals

## Variables

Named storage location that maps a symbolic name to a value in memory. The compiler replaces the name with the memory location. Declared with `let`.

```rust title:"main.rs"
fn main(){
    let x = 2;
	println! ("x = {}", x);
}
```

In Rust all variables are immutable by default unless explicitly declared as mutable.

```rust title:"main.rs"
fn main(){
    let mut x = 2;
	println! ("x = {}", x);
	x = 3;
	println! ("x = {}", x);
}
```

## Data Types

Rust is statically typed, data types must be known at compile time. The type can be inferred or explicitly annotated with a colon.

```rust title:"main.rs"
fn main(){
    let x:i32 = 2;
	println! ("x = {}", x);
}
```

Data types can be categorized into scalar and compound. Scalar are integers, floating-point, characters and Boolean.  Signed integers use 1 bit to represent the sign, they can be used for positive and negative values. Unsigned used al the bits to represent the value. The default integer value is `i32`

| Data Type | Annotation           | Type   | Description                                                         |
| --------- | -------------------- | ------ | ------------------------------------------------------------------- |
| Integer   | 8, 16, 32, 64, 128   | Scalar | Numerical values (unsigned - u, signed - i) with no fraction.       |
| Floating  | f32, f64             | Scalar | Numerical values with decimal point. Single or double precision.    |
| Boolean   | bool                 | Scalar | Boolean value of 1 byte. Can be `true` or `false`                   |
| Chars     | char (Single quotes) | Scalar | Unicode scalar values 4 bytes in size. Unicode values as `'\u{2A}'` |

```rust title:"main.rs - Scalar Data Types"
fn main(){
    println!("=== SCALAR TYPES ===\n");
    println!("--- Signed Integers ---");
    let i8_val: i8 = -128;
    let i16_val: i16 = -32768;
    let i32_val: i32 = -2147483648;
    let i64_val: i64 = -9223372036854775808;
    let i128_val: i128 = -170141183460469231731687303715884105728;
    let isize_val: isize = -42;    
    println!("i8: {} (type: {})", i8_val, type_of(&i8_val));
    println!("i16: {} (type: {})", i16_val, type_of(&i16_val));
    println!("i32: {} (type: {})", i32_val, type_of(&i32_val));
    println!("i64: {} (type: {})", i64_val, type_of(&i64_val));
    println!("i128: {} (type: {})", i128_val, type_of(&i128_val));
    println!("isize: {} (type: {})", isize_val, type_of(&isize_val));
    
    println!("\n--- Unsigned Integers ---");
    let u8_val: u8 = 255;
    let u16_val: u16 = 65535;
    let u32_val: u32 = 4294967295;
    let u64_val: u64 = 18446744073709551615;
    let u128_val: u128 = 340282366920938463463374607431768211455;
    let usize_val: usize = 42;
    println!("u8: {} (type: {})", u8_val, type_of(&u8_val));
    println!("u16: {} (type: {})", u16_val, type_of(&u16_val));
    println!("u32: {} (type: {})", u32_val, type_of(&u32_val));
    println!("u64: {} (type: {})", u64_val, type_of(&u64_val));
    println!("u128: {} (type: {})", u128_val, type_of(&u128_val));
    println!("usize: {} (type: {})", usize_val, type_of(&usize_val));
    
    println!("\n--- Floating Point ---");
    let f32_val: f32 = 3.141;
    let f64_val: f64 = 2.718;
    println!("f32: {} (type: {})", f32_val, type_of(&f32_val));
    println!("f64: {} (type: {})", f64_val, type_of(&f64_val));
    
    println!("\n--- Boolean ---");
    let bool_true: bool = true;
    let bool_false: bool = false;
    println!("bool (true): {} (type: {})", bool_true, type_of(&bool_true));
    println!("bool (false): {} (type: {})", bool_false, type_of(&bool_false));
    
    println!("\n--- Character ---");
    let char_val: char = '🦀';
    let char_ascii: char = 'A';
    println!("char (emoji): {} (type: {})", char_val, type_of(&char_val));
    println!("char (ASCII): {} (type: {})", char_ascii, type_of(&char_ascii));

}
```

Compound data types can store multiple values, they are Arrays and Tuples. For mutable tuples only their values are allowed to mutate, their data type or tuple size remain fixed.

| Data Type | Annotation              | Type     | Description                                                                                                                                                             |
| --------- | ----------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tuples    | `(value1, value2, ...)` | Compound | Collection of related items, they can store a mix of data types. Fixed in length once declared with zero based indexing. Period based index access as `tuple.1`         |
| Array     | `[value1, value2, ...]` | Compound | Collection of items with the same data type. They are stored sequentially in memory. Fixed in length with zero based indexing. Bracket based index access as `array[1]` |

```rust title:"main.rs - Compound Data Types"
fn main(){

    println!("--- Tuple ---");
    let tuple: (i32, f64, char, bool) = (42, 3.141, 'R', true);
    println!("Tuple: {:?} (type: {})", tuple, type_of(&tuple));
    println!("Element access: {}, {}, {}, {}", tuple.0, tuple.1, tuple.2, tuple.3);

    println!("\n--- Unit Type ---");
    let unit: () = ();
    println!("Unit: {:?} (type: {})", unit, type_of(&unit));
    
    // Array
    println!("\n--- Array ---");
    let array: [i32; 5] = [1, 2, 3, 4, 5];
    println!("Array: {:?} (type: {})", array, type_of(&array));
}
```

Variables can be declared without assigning a value as long as the data type is specified, before using this variables you will need to initialize them. If you want to initialize an array with the same value Rust recommends to use a repeat expression as `array = [0;3]` instead of `array = [0,0,0]`. Notice that the rust compiler will panic at compile and even run-time if we try to access an index out of bounds, this is done for memory safety by preventing invalid memory access.

## Comments

Single-line comments use double forward slash `//`. Multi-line comments use `/**/`.
## Functions

Functions organize code into modules to be reused. The function `main()` is a special function present in every Rust program as the entry point for execution. Functions are declared using `fn` with the name of the function and arguments inside parentheses (must have their type specified).

```rust title:"main.rs - Function Definition"
fn function_name(arg1:type, arg2:type,...){
	// Code
}
```

It is recommended to use underscores for multi-word function identifiers. A function body can consist of statements or expressions. Statements perform an action without returning a value while expressions evaluate to produce a resulting value. A function can return a value explicitly with `return`.

Functions that are expected to return a value must have the data type of the return value specified with `->` such as `fn sum(x:i16, y:i16) -> i16` . If it is expected to return multiple values you can use a tuple such as `fn sum_v2(x : i16, y : i16) -> (i16, i16, i16)`. There is an implicit return activated when the last statement in the function body is an expression, such as `fn sum(x : i16, y : i16) -> i16 { x + y }`.

## Control Flow

Control flow tools like conditionals and loops allow us to execute repeating code or based on certain conditions. An `if` expression is used for conditional execution, for mutually exclusive blocks we can use `if ... else` expressions. For multiple non-overlapping conditions you can use the `if .. else if` expressions.

```rust title:"main.rs - Conditionals"
fn main(){
	let a = 10;
	if a == 10 {
		println!("a is 10");
	} else {
		println!("a is not 10");
	}

	let grade = 67;
	if grade > 90 {
		println!("A");
	} else if grade > 80 {
		println!("B");
	} else if grade > 70 {
		println!("C");
	} else if grade > 60 {
		println!("D");
	} else {
		println!("F - Failed!");
	}

}
```

To execute a block of code multiple times we can use a `loop`,  `while` or `for` loop to do so. Code inside a loop block runs indefinitely until explicitly stopped with `break` or the program terminates. You can pass a value after the break expression to be returned by the loop block.
*italic*
A `while` block will keep running until a condition becomes false. A `for` block is used to iterate over the elements of a collection, you could do it with a while loop and a counter but it is preferred to use a `for` loop for performance and safety reasons.

```rust title:"main.rs - Loops"
fn main(){
	let mut a = 5;
	let finalA = loop {
		a -= 1;
		println!("a={}", a);
		if a == 2 {
			break a;
		}
	}
	println!("Loop result = {}", finalA);
	
	let mut b = 5;
	while b > 2 {
		b -= 1;
		println!("b={}", b);
	}
	
	let values = [1,2,3,4];
	for value in values.iter() {
		println!("value = {}", value);
	}
}
```

# Egui

GUI libary for rust that runs natively or on the web, also available as a libary on many game engines. It is a very simple, easy to use GUI library. It uses the Eframe framework meaning it supports Linux, Mac, Windows, Android and Web. 

```rust
ui.heading("My egui Application");
ui.horizontal(|ui| {
    ui.label("Your name: ");
    ui.text_edit_singleline(&mut name);
});
ui.add(egui::Slider::new(&mut age, 0..=120).text("age"));
if ui.button("Increment").clicked() {
    age += 1;
}
ui.label(format!("Hello '{name}', age {age}"));
ui.image(egui::include_image!("ferris.png"));
```
